## طرح و ساختار نتیجه

ساختار پیشین: سلام و نقش → کارت‌های دسترسی سریع → پیام فعال بودن حساب.

ساختار جدید: سربرگ و ناوبری → ۵ شاخص قابل محاسبه → وظایف من و پروژه‌ها → اسپرینت فعال، بار کاری مدیر، گفتگوها → میان‌برهای معتبر. عدد ساختگی، تخمین زمان کار یا «امتیاز سلامت» اختراعی استفاده نشده است. پیشرفت از وضعیت تمام تسک‌های فعال پروژه حساب می‌شود؛ تسک‌های soft delete لحاظ نمی‌شوند.

کوئری داشبورد در `lib/dashboard-data.ts` با `select` محدود و شمارش/گروه‌بندی روی سرور انجام می‌شود. برای مدیران، کارهای تیم فقط در پروژه‌های تحت مدیریت و کارهای خود مدیر در پروژه‌های عضو نمایش داده می‌شوند. برای کارمند، شاخص‌های وظیفه و گفتگو فقط از تسک‌های واگذارشده در پروژه‌های عضو می‌آیند. تاریخ‌ها با منطقهٔ زمانی تهران و تقویم فارسی نمایش داده می‌شوند.

## بررسی انجام‌شده

- `npx tsc --noEmit`: PASS
- `npm run lint`: PASS
- `npm run build`: PASS پس از آخرین تغییرات رابط
- `npm run test:unit`: PASS، ۱۰ تست
- `npm run test:integration`: PASS، ۲۵ تست با PostgreSQL ایزوله، شامل ۲ تست جدید برای داشبورد و RBAC
- Chrome headless با دادهٔ موقت در دیتابیس تست: viewport ۳۷۵، ۷۶۸، ۱۳۶۶ و ۱۹۲۰ پیکسل؛ `scrollWidth <= clientWidth`، کنترل‌های تعاملی بدون بریدگی افقی، لینک پرش معتبر و نمایش صحیح لینک مدیریت کاربران فقط برای ادمین: PASS. نمای کارمند در ۳۷۵ پیکسل نیز بررسی شد.
- فرم ورود در viewport ۳۷۵ پیکسل: ورودی‌ها حاضر و بدون اسکرول افقی. بررسی دستی تمام مسیرهای فرم و کار با صفحه‌خوان انجام نشد.

## موارد باقیمانده

- ممیزی کامل WCAG 2.2 AA با صفحه‌خوان، زوم ۲۰۰٪ و آزمون دستی کیبورد هنوز انجام نشده است. تست خودکار و عکس مرورگر جای آن را نمی‌گیرند.
- کانبان تغییر وضعیت با select جایگزین کشیدن دارد؛ بررسی دستی کامل تعامل‌های drag و timeline در همهٔ عرض‌ها باقی است.
- برای داده‌های بسیار بزرگ، گروه‌بندی همهٔ پروژه‌های در دسترس نیاز به پایش زمان پاسخ و احتمالاً صفحه‌بندی/تجمیع بیشتر دارد.
- دیتابیس توسعهٔ معرفی‌شده در `.env` هنوز migration فاز سوم را نگرفته است؛ صفحه‌های وابسته به `Task.deletedAt` تا اجرای migration افزایشی روی آن کار نمی‌کنند. هیچ migrationی روی دیتابیس توسعه یا Production در این مأموریت اجرا نشد.
- افزودن «وابستگی وظایف» یا برآورد ساعت کار به schema/منطق جدید نیاز دارد؛ برای داشبورد فعلی لازم نیست و بدون تأیید اجرا نشده است.
